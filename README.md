# The Silent One

This repo contains the static website for The Silent One, a faith-themed poker-table experience with lobby, scripture page, and gameplay screen.

## Pages
- `index.html` — lobby and character selection
- `thefire.html` — scripture and doctrine content
- `thegame.html` — poker table interface

## Hosted site
GitHub Pages can be enabled from the repository settings if the repo is public. For a private repo, GitHub Pages is not the same as a free private website option.

## Collaborators
To allow others to collaborate, use GitHub repository settings:
- Settings → Collaborators and teams
- Add the GitHub usernames you want
- Choose write/admin permissions as needed

## Notes
- This is a static site and is easy to maintain in GitHub Pages.
- The repository can be made private later if you want tighter control, but that changes the hosting model.
